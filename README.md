# 🚚 Smart Logistics Engine

A logistics optimization and simulation system built using C++, Flask, HTML, CSS, and JavaScript.

## Features

- Shortest Path Calculation using Dijkstra's Algorithm
- Route Optimization using TSP-inspired planning
- Delivery Allocation using Greedy/Knapsack techniques
- Dynamic Traffic Simulation
- Road Block Detection and Handling
- Live Event Generation
- Performance Analysis with Execution Time Tracking
- Multi-Agent Delivery Planning
- Interactive Dashboard Interface

## Tech Stack

- C++
- Data Structures & Algorithms
- Flask
- HTML
- CSS
- JavaScript
